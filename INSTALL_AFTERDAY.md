# AFTERDAY Server — комплект настройки

Этот комплект настраивает обновлятор лаунчера и автоматическую публикацию релизов GitHub для репозитория `afterdayrevival/afterday-server`.

## Что входит в комплект

- `.gitignore` — исключает локальные настройки, ключи, сертификаты, журналы, сохранения и собранные архивы.
- `.github/workflows/release.yml` — автоматически собирает и публикует релиз после отправки тега, начинающегося с `20`.
- `tools/build_release.py` — создаёт `manifesto.json` и `atualizacao.zip` с контрольными суммами SHA-256.
- `launcher/atualizador.py` — проверяет обновления в репозитории AFTERDAY.
- `launcher/publicar_versao.py` — собирает пакет для публикации и использует новый репозиторий.
- `README.md` — описание проекта и порядок публикации.

## Установка в локальный проект

1. Сделайте резервную копию текущей папки проекта.
2. Распакуйте комплект в корень проекта, разрешив замену соответствующих файлов.
3. Проверьте, что в `launcher/atualizador.py` указан `REPO_PADRAO = "afterdayrevival/afterday-server"`.
4. Проверьте, что в `launcher/publicar_versao.py` указан `REPO = "afterdayrevival/afterday-server"`.
5. Не отправляйте в GitHub локальные `config.json`, `host.txt`, `steamid.txt`, ключи, сертификаты, журналы, сетевые дампы и сохранения игроков.
6. Добавляйте исходники другого проекта только при наличии разрешения автора или подходящей лицензии. В исходном репозитории не обнаружен опубликованный файл LICENSE; открытый доступ сам по себе не даёт права на распространение кода.

## Отправка исходников в GitHub

После добавления исходников, которые разрешено распространять, выполните в PowerShell:

```powershell
git clone https://github.com/afterdayrevival/afterday-server.git
cd afterday-server
# Скопируйте разрешённые исходники проекта, сохранив структуру папок.
git add .
git status
git commit -m "Добавлены исходники AFTERDAY Server"
git push origin main
```

## Публикация автоматического обновления

```powershell
git add .
git commit -m "Подготовлено обновление AFTERDAY"
git push origin main
git tag 2026.11.10-1
git push origin 2026.11.10-1
```

После отправки тега GitHub Actions автоматически соберёт и опубликует два файла обновления. Не отправляйте тег до добавления разрешённых исходников: сборка завершится ошибкой, если ей нечего упаковывать.

Для работы используется встроенный `GITHUB_TOKEN` с разрешением `contents: write`. Создавать личный токен и добавлять секреты в репозиторий не требуется.
